# Gardening UI artwork v1

Generated with the built-in OpenAI ImageGen workflow on 18 October 2026. The
source PNG is retained untouched as `seed-satchel-master.png`.

## Runtime mapping

- `seed-satchel-master.png` →
  `public/assets/garden/seed-satchel-v1.png` (512×512, transparent PNG)

The illustration is a worn gardener's seed satchel, softly open with a few
unlabelled seed packets, folded linen, a brass clasp and a small sprout. It is
used in the empty seed-satchel state on `/skills/Gardening`.

## Generation direction

The prompt requested a premium hand-painted dark-fantasy RPG inventory
illustration with a centred readable silhouette, warm upper-left light and a
genuinely transparent background. It excludes scenery, a UI frame, text,
watermarks, hands and magical effects.
