# Fishing baits v1 artwork

Fifteen original transparent masters generated with the built-in image generator on 2026-09-24. Runtime exports are the matching 256×256 RGBA sprites in `public/assets/items/consumables/bait/`.

The visual contract is deliberately strict: every asset contains only the bait itself. There are no hooks, lines, containers, wood, bark, reeds, leaves, water, ground, cast-shadow stages, labels, or other supporting props.

All sprites use the Aergyle “Wayfarer's Atlas” direction: a centered, hand-painted fantasy inventory silhouette with broad faceted value planes, warm upper-left lighting, cool self-shadows, and a genuinely transparent background.
