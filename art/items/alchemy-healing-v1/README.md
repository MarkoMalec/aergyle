# Alchemy healing artwork

These are the source-resolution PNG masters for the healing-potion expansion.
The deployable versions are 256×256 transparent PNGs under
`public/assets/items/`.

The visual brief is a transparent illustrated inventory asset: red liquid inside
clear glass, with a deliberately increasing flask silhouette from Minor through
Big, then the largest and most heavily sealed Trollblood Elixir. Herb, Water
and Troll Blood assets use the same clean, readable inventory treatment.
