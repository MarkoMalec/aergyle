# Tailoring v1 asset masters

Generated with the built-in OpenAI ImageGen tool on 2026-09-15. The untouched
1254px RGBA masters are stored here; runtime copies were resized to 256×256 RGBA
PNGs under `public/assets/items`.

## Prompt set

All armor prompts requested a centered, three-quarter, hand-painted fantasy RPG
inventory sprite on a genuinely transparent background with generous padding,
soft warm studio lighting, no character, text, frame, logo or watermark. The
Fieldweave visual language is moss-green woven cloth, warm-brown soft leather,
muted ivory spider-silk stitching, restrained leaf details and realistic
materials. Subjects were the tunic, matching gloves, matching mid-calf
trailboots and matching reinforced leggings.

All material prompts used the same transparent, centered inventory treatment:

- Cloth Scraps: a twine-tied bundle of moss, ivory and tan woven remnants.
- Soft Hide: one folded warm-brown hide with a lighter suede underside.
- Spider Silk: one silvery-white, subtly iridescent skein with a loose loop.

All blueprint prompts requested a partially unrolled aged parchment containing
a recognizable dark-sepia tailor's pattern of its referenced Fieldweave piece,
stitch diagrams and nonlinguistic measurement ticks, fastened with moss-green
cord and a leaf seal. Readable words, letters and numbers were excluded. One
unique blueprint was generated for the tunic, gloves, trailboots and leggings.

Existing Aergyle inventory art was supplied as a style reference; each output
is newly generated for this pack.
