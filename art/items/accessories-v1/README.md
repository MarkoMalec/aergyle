# Wayfarer accessories v1

Six low-tier accessory masters generated with OpenAI's built-in image generator
on 2026-09-18. The untouched source images are retained here; optimized 256x256
RGBA runtime sprites live under `public/assets/items`.

image was generated independently on a genuinely transparent canvas, then
visually inspected before its runtime derivative was created.
