# Hunting animal artwork

Mode: `create` (ImageGen), followed by a deterministic 256×256 RGBA runtime
resize. Generated 1254×1254 masters are retained in this directory.

Shared prompt:

> Create one isolated animal bestiary sprite for an idle fantasy MMO. Use
> polished hand-painted, lightly faceted, grounded medieval-fantasy game art;
> believable anatomy; a chunky readable silhouette; restrained natural colors;
> warm upper-left light; cool lower-right shading; and a subtle contact shadow.
> Show the complete animal in a calm, alert three-quarter side pose, centered
> with transparent padding on a square canvas and legible at 48px. No scenery,
> frame, pedestal, glow, particles, text, watermark, hunter, weapon, trap,
> injury, blood, or gore.

Subjects: tawny Meadow Hare, antlered Red Deer stag, dark-bristled Wild Boar,
silver Grey Wolf, olive Marsh Crocodile, cream Mountain Goat, pale blue-gray
Frostfang Lynx, and charcoal-brown Ashback Bear. The last two use only restrained
fantasy traits while preserving believable anatomy.

Runtime exports are in `public/assets/creatures/animals/`.
