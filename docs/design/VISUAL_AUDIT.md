# Aergyle visual audit

Audited on the `redesign` branch, 14 September 2026. The active application is Next.js 14 with the App Router, Tailwind 3, Radix primitives, dnd-kit, React Query, and Prisma/MariaDB. Its development server uses port 3001 in the review environment.

## Scope and architectural constraints

- Root: `src/app/layout.tsx`, `src/styles/globals.css`, `tailwind.config.ts`.
- Public: `/`, `/signin`, `/register`, and the parallel sign-in/register slots under `/play`.
- Game: shared authenticated layout; `/profile`; `/skills/[name]` including Gardening plots and Gathering expeditions; `/map`; `/marketplace`; `/marketplace/my-listings`.
- Shared presentation: Radix-based buttons, cards, dialogs, tooltips, popovers, selects, badges, tables; header, sidebar, portrait, XP, inventory/equipment and item details; resource start and completion dialogs; travel, seed selection, stack splitting and market listing.
- Administration: existing `.admin-theme` and item, rarity, skill, location, progression, Gardening, and Gathering editors. Keep their operational layout and database controls.
- Game state: retain contexts, service calls, query keys, realtime events, equipment indices, inventory slots, travel, Gardening, and Gathering timers, prices, tax, rarity tiers and progression calculations.

## Source findings

| Finding                                                                                      | Consequence                                                                              | Direction                                                                                                               |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Dark body but white card/popover tokens; additional `.dark` and admin palettes               | Public sign-in button nearly disappears; dialogs and item details use unrelated surfaces | One intentional default dark palette; retain the admin override                                                         |
| Geist declared at root, Google Inter in a second nested html/body                            | Font drift, invalid document nesting and potential hydration issues                      | One root document; locally available Geist throughout, confident modern headings                                        |
| Fixed 288px rail, unconditional `pl-72`, generous nested containers                          | Game content is squeezed and inaccessible on small screens                               | Responsive shell with one inset, compact rail and a proper mobile sheet                                                 |
| Huge portrait, free-floating equipment, repeated bracer/pauldron drop IDs                    | Inventory is buried; equipment anatomy is visually ambiguous                             | Anatomical equipment board, labelled slots and unique identities for paired visual targets                              |
| Item art fills uneven slots; quantity hangs outside; rarity often only appears after opening | Collection is difficult to scan                                                          | Stable specimen recess, contained quantity plaque, full rarity frames, a controlled aura and distinct high-tier symbols |
| Nearest-Tailwind rarity mapping falls back to grey for custom database hex values            | Admin-configured colours may silently disappear                                          | Use validated CSS custom properties; retain database overrides                                                          |
| Cards and stop badges are clickable divs                                                     | Keyboard and touch access is inconsistent                                                | Native buttons, visible focus and textual states                                                                        |
| Fishing/Mining/Gathering headings contain development placeholders                           | Player lacks location and task context                                                   | Consistent vocation heading and useful description                                                                      |
| Skill columns total more than 100% of width; garden contains tiny long timers                | Poor tablet/phone layout                                                                 | Content/progress grid that stacks; garden retains six logical columns with readable minimum tile widths                 |
| Large map and nonfunctional anchor markers                                                   | Scroll/layout leakage and false affordances                                              | Bounded scrollable atlas, keyboard scrolling, informational markers; actual travel remains in its existing control      |
| Saturated green, yellow, blue, red and emoji compete in stats/progression                    | Every value has equal visual urgency                                                     | Brass for action/currency, verdigris for progress, colour only for semantic exceptions                                  |
| Homepage has empty showcase rectangles, very large spacers and no clear entry path           | Strong artwork is disconnected from game access                                          | Compact illustrated entry with working sign-in/register links and real game activities                                  |
