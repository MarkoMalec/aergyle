# Aergyle vocation icons v1

Twelve 256×256 transparent WebP icons for the playable vocation pages:

- `woodcutting.webp`
- `mining.webp`
- `fishing.webp`
- `gardening.webp`
- `gathering.webp`
- `hunting.webp`
- `alchemy.webp`
- `blacksmithing.webp`
- `weaponsmithing.webp`
- `carpentry.webp`
- `cooking.webp`
- `tailoring.webp`

They are original, isolated hand-painted medieval-fantasy tool emblems. The
shared direction is grounded material work, broad lightly faceted values,
warm upper-left light, cool teal-grey self-shadows, and ample transparent
padding so the art remains readable at 24–32px. They deliberately contain no
text, UI frame, scene, character, logo, or copied visual treatment from the
reference game.

Generated with the built-in image generation tool on 19 October 2026 and
exported from transparent 1254px PNG masters to 256px WebP at quality 90.

`Forge` is intentionally not included: it is not a player-facing vocation
page in the current application (`src/game/crafting.ts`). Attribute/stat icon
art was explicitly deferred, including Mana and Mana Regeneration.
